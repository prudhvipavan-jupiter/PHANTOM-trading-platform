## 🚀 **Getting Started**

### **Prerequisites**
```bash
Node.js 18+ 
npm or yarn
```

### **Installation**
```bash
# Clone the repository
git clone https://github.com/your-username/P.H.A.N.T.O.M.git

# Navigate to frontend
cd P.H.A.N.T.O.M-frontend

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
